# Personalized Recommendations

The platform uses transparent, rule-based scoring rather than machine learning. Each open, unseen opportunity earns +3 for a category the student has bookmarked or applied to, +2 for matching eligibility (or “all”), and +1 for a deadline within 14 days. Each recommendation displays a human-readable reason, and new users see opportunities ordered by soonest closing date.

Resume-based matching and machine-learning-based recommendations are not implemented and remain future work.
